后台-AI订单 · 开发说明V3.0.6

  • 模块入口：订单管理 → AI订单（新增菜单，位于「MCP订单」下方）；列表筛选、创建流程均基于原 MCP订单 页面改造
  • 列表：沿用原订单字段并新增「备注」列（位于订单编号与操作之间）；「MCP点数」列替换为「AI积分」（带「新增」标记）；订单类型固定为 AI订单
  • 筛选：创建时间 / 订单状态 / 是否续费订单 / 订单类型（全部、AI订单）/ 订单来源 / 手机号
  • 创建手工订单：手机号 + 选择 AI 套餐（自动带出积分与金额，可调）+ 支付金额；校验手机号为主账号
  • 创建赠送订单：手机号 + AI 套餐 + 赠送时长 + 赠送AI积分 + 备注；交易金额为 0
  • 积分明细：操作列「明细」弹窗查看该用户的充值明细（订单号 / 套餐 / 积分变动）与消耗明细（功能模块 / 消耗），双 Tab 切换并汇总
  • 列表为演示数据，保存在浏览器本地；HTML / CSS / JS 标签可查看对应源码（公共后台样式复用 admin-ai-package.css）
