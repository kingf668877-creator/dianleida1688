OZON 搜索词跨语言匹配规则

基于 AI 输出的三语搜索词分析结果（中/俄/英），对 OZON 商品标题进行五层分层匹配与排序。匹配逻辑由后端代码控制，AI 只负责输出分析结果。

一、核心思路

一句话概括：AI 把用户搜索词拆解为三语关键词结构，后端拿这个结构对商品标题做五层逐层宽松匹配，命中层级越高的排越前面，同一层内按命中语言数和修饰词命中数排序。

设计原则

  • 结果最多、相关度高的排前面：从精准到兜底五层渐进，宁可多召回不错杀
  • 跨语言 OR 匹配：商品标题可能是俄文、中文、英文或三语混拼，任一语言命中即算匹配
  • 匹配排序由后端控制：AI 提示词不包含任何匹配规则，只输出三语分析 JSON
  • 同语言加权：标题中同一语言命中的关键词越多，相关度越高（可选加分项）
L1
必含词[0]（任意语言）＋全部修饰词（每个修饰词任意语言命中）→ 最精准，排最前
L2
某个扩展词完整命中（三语中任一完整短语出现在标题）→ 精准
L3
必含词[0]（任意语言）＋某个扩展词的全部拆词（每个拆词任意语言命中）→ 宽松
L4
必含词[0]（任意语言）＋部分修饰词（至少1个修饰词任意语言命中）→ 宽松
L5
仅必含词[0]（任意语言）命中 → 兜底召回，排最后
关键概念：跨语言 OR每个关键词在 AI 输出中都有 {zh, ru, en} 三个版本。匹配时，只要三个版本中任意一个出现在商品标题中，就算该关键词命中。例如必含词[0]是 外套/пальто/coat，标题写 "мужское пальто" 命中 пальто → 算命中。

二、AI 输出数据结构

后端接收到的 AI 分析结果为以下 JSON 结构。每个关键词字段都是三语对象，匹配时对三语做 OR 判断。

{
  "coreProduct": {"zh":"外套", "ru":"пальто", "en":"coat"},
  "brand": {"zh":"", "ru":"", "en":""},
  "modifiers": { "style": [{"zh":"休闲", "ru":"повседневное", "en":"casual"}], "material":[], "crowd": [{"zh":"男士", "ru":"мужское", "en":"men's"}], "scene":[], "brand":[] },
  "expandedKeywords": [{"zh":"男士休闲外套", "ru":"мужское повседневное пальто", "en":"men's casual coat"}],
  "requiredKeywords": [{"zh":"外套", "ru":"пальто", "en":"coat"}]
}

字段说明

字段类型匹配中的角色说明
coreProductTrilingual参考核心品类词，供理解用，实际匹配用 requiredKeywords[0]
brandTrilingual修饰词品牌名，归入 modifiers.brand 一起参与匹配
modifiers.styleTrilingual[]修饰词款式/特征词，如休闲、加厚、折叠
modifiers.materialTrilingual[]修饰词材质词，如羊绒、PVC、硅胶
modifiers.crowdTrilingual[]修饰词人群词，如男士、儿童、宝宝
modifiers.sceneTrilingual[]修饰词场景/平台词，如跨境、亚马逊、万圣节
modifiers.brandTrilingual[]修饰词品牌数组，与顶层 brand 合并参与匹配
expandedKeywordsTrilingual[]L2 完整匹配扩展词，任一项的任一语言完整出现在标题即命中 L2
expandedTokenGroupsTokenGroup[]L3 拆词匹配每个扩展词的三语拆词，任一语言的 tokens 全部命中即满足 L3 的扩展词条件
requiredKeywordsTrilingual[]必含词[0] 是核心必含词，五层匹配都离不开它；[1] 仅在材质/品牌等场景存在
requiredKeywords[0] 铁律必含词第一个是纯核心品类词（如"外套"而非"男士外套"），crowd/style/scene 等修饰词绝不追加到这里。只有材质是"产品核心定义"时才有 requiredKeywords[1]（如羊绒服装 → ["羊绒","服装"]）。匹配从 L1 到 L5 都以 requiredKeywords[0] 为基础锚点。

三、跨语言匹配机制

3.1 三语 OR 匹配

对任意一个三语关键词对象 kw = {zh, ru, en}，定义基础匹配函数：

matchKeyword(title, kw): return contains(title, normalize(kw.zh)) // 中文命中 OR contains(title, normalize(kw.ru)) // 俄文命中 OR contains(title, normalize(kw.en)) // 英文命中

只要三个语言版本中任意一个在标题中出现，该关键词即算命中。空字符串跳过。

3.2 三语短语完整匹配（L2 用）

对扩展词 expandedKeywords[i] = {zh, ru, en}，完整匹配的判断：

matchExpandedKeyword(title, ek): return contains(title, normalize(ek.zh)) OR contains(title, normalize(ek.ru)) OR contains(title, normalize(ek.en))

注意：L2 是完整短语匹配，不是拆词匹配。例如扩展词 "men's casual coat" 要求标题中连续出现这三个词，不能只出现 "coat"。

3.3 三语拆词全部命中（L3 用）

对 expandedTokenGroups[i]，它包含三个语言版本的拆词：

matchTokenGroup(title, group): zh_all = ALL(group.zh.tokens, t => contains(title, normalize(t))) ru_all = ALL(group.ru.tokens, t => contains(title, normalize(t))) en_all = ALL(group.en.tokens, t => contains(title, normalize(t))) return zh_all OR ru_all OR en_all

任一语言版本的所有拆词都出现在标题中（不需要连续），该 tokenGroup 即算命中。

3.4 同语言加分（可选，层内排序用）

同一层级内，如果命中的关键词集中在同一语言（如标题全是俄文，所有词都命中俄文版），相关度更高，可在层内排序时加分。

sameLangBonus(title, matched_keywords): zh_hits = count matched where zh version hit ru_hits = count matched where ru version hit en_hits = count matched where en version hit return max(zh_hits, ru_hits, en_hits)
实现建议：同语言加分不影响层级归属，只在同一层内排序时作为 tiebreaker。如果开发资源有限，可以先不实现，不影响核心匹配逻辑。

四、五层匹配规则详解

每个商品标题按 L1 → L2 → L3 → L4 → L5 顺序依次判断，命中最高层即停止，不再往下判断更低层。最终按层级从高到低排序输出。

必含词[0] + 全部修饰词 排名最高

标题命中必含词[0]的任意语言版本，且所有非空修饰词（style + material + crowd + scene + brand）各自至少有一个语言版本命中。

condition: matchKeyword(title, requiredKeywords[0]) AND ALL(modifiers, m => matchKeyword(title, m))

含义：用户搜索词的核心品类和所有限定条件都满足，是最精准的匹配。

某个扩展词完整命中 排名第二

标题中完整出现任意一个扩展词的三语版本之一（连续短语匹配）。

condition: ANY(expandedKeywords, ek => matchExpandedKeyword(title, ek))

含义：商家标题里直接写了 AI 扩展出的精准长尾词，相关度高。

必含词[0] + 某个扩展词全部拆词 排名第三

标题命中必含词[0]的任意语言版本，且任意一个 tokenGroup 的某一语言版本的所有 tokens 都命中（不要求连续，不要求与必含词同语言）。

condition: matchKeyword(title, requiredKeywords[0]) AND ANY(expandedTokenGroups, g => matchTokenGroup(title, g))

必含词[0] + 部分修饰词 排名第四

标题命中必含词[0]的任意语言版本，且至少命中一个非空修饰词的任意语言版本。

condition: matchKeyword(title, requiredKeywords[0]) AND ANY(modifiers, m => matchKeyword(title, m))

仅必含词[0]命中 排名最后

标题只命中必含词[0]的任意语言版本，没有命中任何修饰词，也不满足上层条件。

condition: matchKeyword(title, requiredKeywords[0])

含义：只要品类对了就展示给用户，宁可多召回。这是结果最多的一层。

层间关系图

// 对每个商品标题执行
if (match_L1(title))      -> layer = 1
else if (match_L2(title)) -> layer = 2
else if (match_L3(title)) -> layer = 3
else if (match_L4(title)) -> layer = 4
else if (match_L5(title)) -> layer = 5
else                      -> 不展示

// ORDER BY layer ASC, modifiers_hit_count DESC, same_lang_score DESC

requiredKeywords[1] 的处理

当 AI 输出 requiredKeywords 有两个元素时（如羊绒服装 → ["羊绒","服装"]），两个都必须命中才算满足必含词条件：

matchRequired(title): return ALL(requiredKeywords, rk => matchKeyword(title, rk))

即 L1/L3/L4/L5 中的"必含词[0]命中"统一替换为"所有 requiredKeywords 命中"。L2 不受影响。

五、文本归一化规则

匹配前对标题和关键词统一做归一化处理，避免大小写、变音符、空格等导致漏匹配。

处理项适用语言规则示例
大小写归一ENRU统一转小写"Coat" → "coat"，"ПАЛЬТО" → "пальто"
ё → еRU俄语字母 ё 统一替换为 е"ёж" → "еж"
变音符去除ENNFKD 分解后去除组合变音符号"café" → "cafe"
标点去除全部去除常见标点符号，替换为空格"men's" → "mens"
多空格压缩全部连续空白字符合并为单个空格"men's casual coat" → "mens casual coat"
前后空格裁剪全部trim" пальто " → "пальто"
全角转半角ZHEN全角字母/数字/标点转半角"ＵＳＢ" → "USB"

归一化函数参考（Python）

import unicodedata
import re

def normalize_text(text: str) -> str:
    if not text:
        return ""
    text = text.lower()
    text = text.replace("ё", "е")
    text = unicodedata.normalize("NFKD", text)
    text = "".join(c for c in text if not unicodedata.combining(c))
    text = unicodedata.normalize("NFKC", text)
    text = re.sub(r"[^\w\s\u4e00-\u9fff]", " ", text, flags=re.UNICODE)
    text = re.sub(r"\s+", " ", text).strip()
    return text
中文匹配注意中文不使用分词，直接做子串包含匹配（title.includes(keyword)）。因为中文没有空格分隔，分词反而可能漏匹配。

跨语言混合命中示例

OZON 标题可能三语混拼，匹配逻辑仍然成立：

跨语言混合场景
🌐"Пальто 男士 coat 秋冬"
必含词：пальто 命中（俄文）；crowd：男士 命中（中文）；style：未命中 → L4L4
🌐"Мужское 休闲 пальто"
必含词：пальто（俄文）；crowd：мужское（俄文）；style：休闲（中文）→ 全部命中 → L1L1
🌐"Casual пальто for men"
必含词：пальто（俄文）；crowd：mens（英文）；style：casual（英文）→ 全部命中 → L1L1
关键结论跨语言匹配不要求标题和关键词用同一种语言。每个关键词独立做三语 OR 判断，不同关键词可以命中不同语言。

七、边界情况处理

7.1 空值处理

  • requiredKeywords 为空数组 → 该搜索词无法匹配，返回空结果
  • 某个关键词的 zh/ru/en 中有空字符串 → 该语言版本跳过，只判断非空版本
  • 三个语言全为空 → 该关键词视为不存在，不参与匹配
  • modifiers 全空 → L1 条件等价于 L5（仅必含词）
  • expandedKeywords 为空 → L2/L3 自动跳过，不影响其他层

7.2 品牌词处理

  • 顶层 brand 和 modifiers.brand 数组合并后统一作为修饰词参与匹配
  • 品牌名通常保留原文（如 "Xiaomi"、"Babycare"），三语版本可能相同，不影响 OR 逻辑

7.3 复合产品名

如 "手机壳"、"麻将包" 等复合产品名，AI 会将完整产品名作为 requiredKeywords[0]（不拆分）。

7.4 俄语词形变化

俄语有丰富的格、数、性变化。标题中 "пальто" 可能以 "пальто"（不变格）出现，但 "мужское" 可能变为 "мужская"、"мужской" 等。

当前方案：AI 在输出俄语关键词时，应提供词根或常见形态。后端先做子串包含匹配，不做词形还原。如果后续发现俄语漏匹配严重，可考虑接入俄语词形还原。

7.5 性能考虑

  • 对商品库做全量扫描时，先用 requiredKeywords[0] 的三语版本做粗筛
  • 粗筛后的候选集再执行完整五层判断
  • 商品库量大时建议用 Elasticsearch / OpenSearch 的 multi-match + bool query 实现

def normalize(text):
    """文本归一化：小写、去标点、压缩空格等"""
    ...

def contains(title_norm, keyword_norm):
    if not keyword_norm:
        return False
    return keyword_norm in title_norm

def match_keyword(title, kw):
    return (contains(title, normalize(kw.get("zh", "")))
         or contains(title, normalize(kw.get("ru", "")))
         or contains(title, normalize(kw.get("en", ""))))

def match_token_group(title, group):
    for lang in ["zh", "ru", "en"]:
        tokens = group.get(lang, {}).get("tokens", [])
        if tokens and all(contains(title, normalize(t)) for t in tokens):
            return True
    return False

def classify_layer(title_norm, analysis):
    # 收集所有修饰词，并获取必含词
    modifiers = []
    for key in ["style", "material", "crowd", "scene", "brand"]:
        modifiers += analysis["modifiers"][key]
    required = analysis["requiredKeywords"]
    required_hit = lambda: all(match_keyword(title_norm, rk) for rk in required)

    if required_hit() and all(match_keyword(title_norm, m) for m in modifiers): return 1
    if any(match_keyword(title_norm, ek) for ek in analysis["expandedKeywords"]): return 2
    if required_hit() and any(match_token_group(title_norm, g) for g in analysis["expandedTokenGroups"]): return 3
    if required_hit() and any(match_keyword(title_norm, m) for m in modifiers): return 4
    if required_hit(): return 5
    return 0

def search_products(products, analysis):
    results = []
    for product in products:
        layer = classify_layer(normalize(product.title), analysis)
        if layer > 0: results.append({"product": product, "layer": layer})
    results.sort(key=lambda r: r["layer"])
    return results
